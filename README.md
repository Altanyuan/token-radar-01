A token launch radar that ranks 198 pre-token protocols by implied value, from a sealed DefiLlama snapshot (14 November 2026). The model scores each protocol on its TVL, its seven-day growth, how long it has run with no token, and how many chains it sits on. The 40-protocol watchlist is covered in full; wrapped, staked and bridged products of tokens that already trade are set aside, not ranked as launches. Every row carries a seven-step farm plan with what it costs and how long it takes, and the dashboard answers which protocol is worth farming next, and what to do about it.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input /path/to/snapshot.json
```
